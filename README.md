## 🛠️ Global Setup

Many of these projects are containerized with Docker or deployable to Render. Refer to the individual `README.md` files within each project directory for specific setup, training, and execution instructions.

*Note: Large model weights (`.pth`, `.pkl`), datasets (`.csv`), and videos (`.mp4`) are excluded from this repository via `.gitignore` to maintain a lean repository size.*
